# notebooks — 面向读者的公开复现文件

## `qPAH_model_M31.ipynb`

从公开数据出发，完整复现 **M31 的 qPAH 经验模型**，并证明 **AGB 恒星密度对模型没有贡献**。

### 内容

1. **数据来源**（含自动下载）
2. **完整筛选链**（每一步的通过数都打印出来）
3. **特征构造**：观测量取 log10、CO 未探测置 0、去投影盘面坐标
4. **训练/测试划分**（10 个 36° 方位扇区，6 训练 / 4 留出）
5. **训练两个模型**：有 AGB / 没有 AGB（**锁在同一批像素上**）
6. **★ χ² 分布对比图** —— 三条面板里两条曲线几乎完全重合，直观证明 AGB 无用
7. **3 面板图**（观测 / 预测 / 相对误差 χ）—— 不含绝对误差面板：
   拟合与评估都用 1/σ² 加权，未加权的绝对误差图只被高 σ 像素主导，没有诊断价值
8. 径向诊断
9. 结论与两个必须在论文里声明的注意事项（qPAH 下界截断、24.9″ 波束过采样）

```
pipeline rows                     124334  100.00%

CO_sigma > 0                      121885   98.03%
qpah_err <= 2.0                   113500   91.29%
R <= 18 kpc                       110094   88.55%   （Draine+2014 的可靠性边界）
H1 >= 3 sigma_H1                  110028   88.49%   （HI 质量判据，只用误差图，不设绝对值下限）
CO footprint 边缘距 >= 20 px        88704   71.34%   （CO 拼接图在边界处不可靠）
```
其中 `qpah == 0` 的 1,542 个（1.74%）。

**为什么用 3σ 而不是绝对下限**：本样本 HI 极亮，**中位 S/N ≈ 66，没有任何像素低于 1σ**，
所以 3σ 只切掉 66 个像素。而绝对下限（110 K km/s，对应 $N_{H\,I}\ge2\times10^{20}$）
听起来很物理，实际会砍掉 **46% 的内环（R<3 kpc）**、且让 χ² 变差 ——
**它切的是真实信号，不是噪声**。

**为什么切 CO 边缘**：距 CO footprint 边界 20 px 内的像素残差显著偏大
（χ² 2.5 vs 1.6，**在固定半径下**亦然），而中位 pull 仍≈0 —— 是额外噪声、不是系统偏差。
这一刀把 χ² 从 1.53 降到 1.29、饱和率从 3.14% 降到 1.40%。

### 为什么用 `Ldust` 而不是 850 μm

`Ldust` 与 `qPAH` 出自**同一次 DL07 拟合**，不严格独立。我们测试了用真正独立的
JCMT/SCUBA-2 850 μm 图（`m31_combined850_um.fits`）替换它：

| 尘埃项 | χ²_all | 标准化系数 |
|---|---|---|
| 无 | 1.1915 | — |
| **Ldust (DL07)** | **1.1748** | **+0.159** |
| 850 μm | 1.1918 | −0.007（等于零） |
| 两者 | 1.1740 | Ldust +0.189，850 μm −0.067 |

850 μm 与 qPAH **边缘相关**很好（log 尺度 Pearson **+0.63**），但在 H1/sfr/CO/H1_ew 已在模型里时
**条件冗余**；Ldust 则不然。故保留 Ldust，并在论文里明写"共享来源"的 caveat。

> **数据警告**：`M31_1d_array_nodust.h5` 里的 `dust_density` 列**是坏的** —— 它来自
> `M31_dust_NH2_sm24.fits`，那张图是**零填充**的（`finite`=100% 但只有 43% >0），
> 对齐时"无数据的 0"被当成真实值参与平均，覆盖边缘被系统性稀释。
> 它与 qPAH 的相关性从正确的 +0.63 掉到 +0.07。**请使用新增的 `dust850` 列。**

### 空间项的选择（留一扇区交叉验证）

**结论：不加任何曲率项。** 在切掉 CO 边缘之前，三次项 y³ 看似能改善 ~7σ；
切掉之后它的增益只剩 1.2850 → 1.2821（Δ=0.003）。
**"需要更复杂的空间模型"这个假象，本来就是 CO 图边缘的伪影造成的。**
最终采用最小的线性项 {x_maj, y_min}。

（参考：星系盘翘曲的标准描述是 $z_w = h_{w,0}(R-R_w)^{\alpha_w}\cos(\phi-\phi_w)$，
即振幅随半径增长的 m=1 方位模式；投影到二维对应基函数 $R^n(\cos\phi,\sin\phi)$。
数据偏好不增长的 n=0 项——即**整体单侧不对称（lopsidedness）**，而非翘曲。）
