# notebooks — 面向读者的公开复现文件

## `qPAH_model_M31.ipynb`

从公开数据出发，完整复现 **M31 的 qPAH 经验模型**，并证明 **AGB 恒星密度对模型没有贡献**。

### 内容

1. **数据来源**（含自动下载）
2. **完整筛选链**（每一步的通过数都打印出来）
3. **特征构造**：观测量取 log10、CO 未探测置 0、去投影盘面坐标
4. **训练/测试划分**（10 个 36° 方位扇区，6 训练 / 4 留出）
5. **训练两个模型**：有 AGB / 没有 AGB（**锁在同一批像素上**）
6. **★ χ² 分布对比图** —— 三条面板里两条曲线几乎完全重合，直观证明 AGB 无用
7. **3 面板图**（观测 / 预测 / 相对误差 χ）—— 不含绝对误差面板：
   拟合与评估都用 1/σ² 加权，未加权的绝对误差图只被高 σ 像素主导，没有诊断价值
8. 径向诊断
9. 结论与两个必须在论文里声明的注意事项（qPAH 下界截断、24.9″ 波束过采样）

### 主要结果（AGB 覆盖区，锁样本）

| | 没有 AGB | 有 AGB |
|---|---|---|
| χ²_red（全部） | 1.3689 | **1.3636** |
| χ²_red（训练） | 1.4658 | **1.4613** |
| χ²_red（留出） | 1.1852 | **1.1782** |
| 中位 \|pull\| | 0.6144 | 0.6142 |
| \|pull\|>3 占比 | 2.23% | 2.21% |

**AGB 标准化系数 = +0.0410**（H1 是 +0.46、Ldust 是 +0.46）；
**Δχ²_red = 0.0053，只有统计误差（0.0140）的 0.38σ** ⇒ **AGB 没有信息量**。

### 空间项的选择（留一扇区交叉验证）

| 空间基函数 | 留出 χ² | vs {x,y} |
|---|---|---|
| 无 | 1.9419 | — |
| {x, y} | 1.6935 | — |
| {x, y, x²} | 1.7870 | 更差 |
| {x, y, y²} | 1.7151 | 更差 |
| {x, y, x², y², xy} | 2.2075 | 差很多 |
| **{x, y, y³}** | **1.6121** | **−0.081（~7σ）** |

**对称二次项通不过验证；短轴三次项 y³ 通过——它正是盘面卷曲（warp）的非对称签名。**
加入 y³ 后线性 y 的系数从 −0.235 塌到 −0.026，说明短轴依赖确实是弯曲的。
