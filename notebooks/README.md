# notebooks — 面向读者的公开复现文件

## `qPAH_model_M31.ipynb`

从公开数据出发，完整复现 **M31 的 qPAH 经验模型**，并证明 **AGB 恒星密度对模型没有贡献**。

### 内容

1. **数据来源**（含自动下载）
2. **完整筛选链**（每一步的通过数都打印出来）
3. **特征构造**：观测量取 log10、CO 未探测置 0、去投影盘面坐标
4. **训练/测试划分**（10 个 36° 方位扇区，6 训练 / 4 留出）
5. **训练两个模型**：有 AGB / 没有 AGB（**锁在同一批像素上**）
6. **★ χ² 分布对比图** —— 三条面板里两条曲线几乎完全重合，直观证明 AGB 无用
7. **3 面板图**（观测 / 预测 / 相对误差 χ）—— 不含绝对误差面板：
   拟合与评估都用 1/σ² 加权，未加权的绝对误差图只被高 σ 像素主导，没有诊断价值
8. 径向诊断
9. 结论与两个必须在论文里声明的注意事项（qPAH 下界截断、24.9″ 波束过采样）

**最终样本里 `qpah == 0` 的像素是 0 个** —— 原来那批"下界堆积"其实是 qPAH 有效区
【外面】1–6 像素宽的一圈薄边，属拟合失败产物，不是物理上的无 PAH 区。
**因此不需要 Tobit 截断似然那种复杂处理**，直接切掉即可。

**为什么切 CO 边缘**：距 CO footprint 边界 20 px 内的像素残差显著偏大
（χ² 2.5 vs 1.6，**在固定半径下**亦然），而中位 pull 仍≈0 —— 是额外噪声、不是系统偏差。
这一刀把 χ² 从 1.53 降到 1.29、饱和率从 3.14% 降到 1.40%。

### 空间项的选择（留一扇区交叉验证）

**结论：不加任何曲率项。** 在切掉 CO 边缘之前，三次项 y³ 看似能改善 ~7σ；
切掉之后它的增益只剩 1.2850 → 1.2821（Δ=0.003）。
**"需要更复杂的空间模型"这个假象，本来就是 CO 图边缘的伪影造成的。**
最终采用最小的线性项 {x_maj, y_min}。

（参考：星系盘翘曲的标准描述是 $z_w = h_{w,0}(R-R_w)^{\alpha_w}\cos(\phi-\phi_w)$，
即振幅随半径增长的 m=1 方位模式；投影到二维对应基函数 $R^n(\cos\phi,\sin\phi)$。
数据偏好不增长的 n=0 项——即**整体单侧不对称（lopsidedness）**，而非翘曲。）
